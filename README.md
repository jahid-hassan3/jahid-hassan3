I am an Undergraduate Student at **Southwest Petroleum University**, focused on **Machine Learning, Predictive Maintenance, Smart Manufacturing, and Data-Driven Systems**.
I build applied AI and simulation workflows that turn sensor telemetry into real-time operational decisions:
* **Current work:** Sensor anomaly detection, time-series health monitoring, and interactive dashboards.
* **Engineering approach:** `data ingestion → feature engineering → model training → web inference → live telemetry`
* **Research direction:** Predictive maintenance pipelines, industrial automation, and edge-deployable ML algorithms.
* **Learning track:** Deep Learning, Time-Series Forecasting, MLOps, and Cloud Microservices.
